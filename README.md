# The Lit List

**A centralized calendar for discovering literary events happening in your city.**

The Lit List is a web platform that brings readings, workshops, open mics, author talks, book launches, and other literary events together in one place.

Literary events are often scattered across bookstore websites, library calendars, newsletters, Eventbrite, Instagram, and other platforms. The Lit List makes them easier to discover by creating a single, searchable calendar for local literary communities.

## Features

- **Browse upcoming events** — Discover literary events happening in your city.
- **Filter events** — Narrow events by location, format, cost, and event type.
- **Explore multiple cities** — Browse dedicated calendars for different literary communities.
- **Find event details** — View descriptions, dates, locations, and registration information.
- **Discover new organizations** — Find events hosted by bookstores, libraries, writing centers, literary organizations, and other community groups.
- **Submit events** — Help expand the calendar by sharing literary events with the community.

## Why I Built It

There are constantly readings, workshops, open mics, author talks, and other literary events happening—but finding them can be surprisingly difficult.

An event might appear on a library calendar, another in a bookstore newsletter, another on Instagram, and another on Eventbrite. Unless you already know where to look, it's easy to miss something you would have loved to attend.

I built The Lit List to solve that discovery problem by creating one place where people can see what's happening across their local literary community.

## How It Works

1. Choose a city.
2. Browse upcoming literary events.
3. Filter by the types of events you're interested in.
4. Click an event to see additional details and registration information.
5. Find something new to read, write, or attend.

## Built With

The Lit List was designed and developed as an independent web project using **Cursor, GitHub, and Render**, with integrations that help aggregate and organize event information.

## Status

The Lit List is live and continuing to grow, with calendars for the **DMV, New York City, San Francisco, Los Angeles, and other communities**.

New events, cities, and features are continually being added.
